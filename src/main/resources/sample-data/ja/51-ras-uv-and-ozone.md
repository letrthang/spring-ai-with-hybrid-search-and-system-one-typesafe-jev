# RAS の基礎 — UV とオゾンによる殺菌

## UV 殺菌装置の働き
UV 殺菌装置は、波長 254 nm の紫外線を出すランプのすぐそばに水を通して、細菌・ウイルス・
寄生虫を殺すか不活化します。紫外線が微生物の DNA を傷つけるので、微生物は増殖できなく
なります。RAS では通常、UV 装置は処理した水が魚の水槽に戻る前の最後の工程です。

## UV 照射量
UV 照射量とは、水が受ける紫外線エネルギーの量で、mJ/cm² で表します。ほとんどの RAS は、
一般的な細菌を抑えるため 30～60 mJ/cm² で設計しますが、一部のウイルスや寄生虫には
100 mJ/cm² 以上が必要です。照射量は、ランプの出力、流量、水の透明度で決まります。

## UV 透過率
UV 透過率 (UVT) とは、紫外線が水 1 cm を通り抜ける割合で、UV 殺菌装置の効き目を左右します。
きれいな RAS の水の UVT は、通常 70～90 % です。にごった水、溶けた有機物の多い水、茶色い
水では UVT が下がり、微生物が受ける照射量が減ります。

## UV ランプとスリーブの保守
UV ランプは古くなると出力が落ちるため、通常 9,000～12,000 時間ごと、つまり年に約 1 回
交換します。ランプを囲む石英スリーブは、バイオフィルムやスケールが光をさえぎるので、
定期的に掃除する必要があります。多くの装置には、出力が下がると知らせる UV 強度センサーが
付いています。

## RAS におけるオゾンの働き
オゾンは強い酸化剤で、RAS の水の溶けた有機物、細かい粒子、亜硝酸、色を分解します。
多くの微生物も殺します。オゾンは水を透明にし、UV 透過率を上げ、プロテインスキマーの
働きも良くするので、多くの養殖場はオゾンと泡分離を組み合わせて使います。

## オゾンの添加量
RAS の一般的なオゾン添加量は、1 日に与える餌 1 kg あたりオゾン約 10～25 g です。
オゾンは、敷地内のオゾン発生装置で乾燥空気か酸素から作ります。添加量は手で決めるより、
ORP の値で制御するのが普通です。

## 残留オゾンが危険な理由
残留オゾンは魚にとって非常に有毒で、水槽の水に 0.01～0.02 mg/L あるだけでもえらを
傷めます。オゾンは、水が魚に届く前に完全に反応させるか、取り除かなければなりません。
残ったオゾンを分解する一般的な方法は、UV 装置、脱気塔、反応槽での十分な接触時間です。

## ORP によるオゾン制御
ORP（酸化還元電位）は水の酸化力をミリボルトで表す値で、オゾン添加を制御する標準的な
方法です。淡水 RAS の水槽は、通常 250～350 mV に保ちます。魚の水槽で約 400 mV を超える
値が出たら、残留オゾンや酸化剤が魚に届いているおそれがあるという警告です。

## スタッフのためのオゾン安全対策
オゾンガスは、空気中の濃度が低くても、頭痛・せき・肺の損傷を起こす人体に有害なガスです。
オゾン発生装置や接触槽のある部屋には、警報を出して発生装置を止めるオゾンガス検知器が
必要です。オゾン反応槽からの排ガスは、分解するか屋外へ排気しなければなりません。

## 海水システムでのオゾン
海水 RAS では、オゾンが臭化物イオンと反応して、魚やエビに有毒な臭素酸などの酸化剤が
できます。これらの副生成物はオゾンそのものより長く残り、オゾンの検査では直接測れません。
そのため海水の養殖場では、淡水の養殖場よりオゾン添加量を少なくし、ORP も低めに保ちます。
