# このデモの仕組み — RAG の概要

## RAG とは何か
RAG（検索拡張生成、Retrieval-Augmented Generation）とは、言語モデルが答える前に、
アプリケーションが質問に関係する文章を探してプロンプトに加える仕組みです。モデルは
記憶だけでなくその文章をもとに答えるので、出典を示すことができ、作り話の答えも
減ります。

## ハイブリッド検索
このデモは、Weaviate を 2 つの方法で検索するハイブリッド検索を使っています。BM25 は、
Cas9 という名前や NGG というコードのように、質問と同じ珍しい単語を含む文章を上位に
並べます。ベクトル検索は、違う言葉を使っていても意味が近い文章を上位に並べます。
Reciprocal Rank Fusion（RRF）は両方の順位を合わせ、各文章は自分が入っているリスト
ごとに 1 / (60 + 順位) の点数をもらいます。

## System 1 と System 2
System 1 は小さくて速い判定モデル（Laya）で、System 2 は最終的な答えを書く大規模言語
モデルです。System 1 は見つかった文章ごとに、型付きの質問に確率で答えます: その文章は
関係があるか、質問に答えられるか、指示を出そうとしていないか。System 2 は OpenRouter 上の
大規模言語モデルで、System 1 が残した文章から最終的な答えを書きます。
